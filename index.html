Deploy

Publish the verified site to GitHub Pages.

What happens automatically?

Every pull request and push to main runs the build and checks. A successful push to main continues to deployment.

  • CI catches common page and build problems early.
  • CD publishes the same built files that passed validation.
  • The deployment job uses GitHub's Pages environment and permissions.
